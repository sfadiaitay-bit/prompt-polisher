# prompt-polisher

A Claude Code mod that turns messy, unstructured text into a well-structured prompt following Anthropic's recommended prompting practices: role, context, task, constraints, examples and output format, written in the same language as your draft (Hebrew stays Hebrew).

## Use

- Click **✨ סדר פרומפט** above the prompt box (where the surface draws it), or
- on any surface, type your messy text, add `++` at the very end and press send. Nothing is sent to the model as a task: the structured prompt replaces the text in the box so you can review it, edit it and send it.

## Install

```
/plugin install prompt-polisher --marketplace sfadiaitay-bit/prompt-polisher
```

Choose **user** scope so it applies to every session.
